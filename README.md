# dotfiles

My personal development configuration built around the terminal.

## Pre-requisites

- macOS (see [`linux`](https://github.com/dedumets/dotfiles/tree/main) for Linux setup)
- [Homebrew](https://brew.sh/)
- CaskaydiaMono Nerd Font
- Cloned repository with included submodules (for TPM)

## Setup

Most dependencies are installed via [Homebrew](https://brew.sh/):

```sh
brew install bat
brew install delta
brew install eza
brew install fzf
brew install neovim
brew install ripgrep
brew install starship
brew install tmux
brew install zoxide
brew install zk
brew install --cask ghostty
brew install --cask nikitabobko/tap/aerospace
```

Unfortunately, some apps must be installed through a GUI:

- [SaneScroll](https://github.com/dyarfaradj/SaneScroll)
