# dotfiles

My personal development configuration built around the terminal.

## Pre-requisites

- UNIX-based operating system with Zsh
- CaskaydiaMono Nerd Font
- Cloned repository with included submodules (for TPM)

## Setup

The `main` branch is only used as a central reference for shared tooling. See [`macos`](https://github.com/dedumets/dotfiles/tree/macos) or [`linux`](https://github.com/dedumets/dotfiles/tree/linux) for specifics.
